# PXAX AI Прогнозы — Telegram Mini App (v0.5)

Мини-приложение для Telegram: ежедневные прогнозы на спорт от ИИ для подписчиков.

⚠️ **Во всех экранах присутствует дисклеймер:** прогнозы генерирует ИИ, вероятность не 100%, ставки — риск, 18+.

## Архитектура

- `index.html` — всё приложение одним файлом (без сборки): UI, свайп-колоды, пейвол
- `scripts/generate-predictions.mjs` — генератор прогнозов по данным ESPN (модель `poisson-v2`, без ключей)
- `scripts/resolve-results.mjs` — резолвер: вчерашние прогнозы сверяются с реальными результатами ESPN + калибровка
- `.github/workflows/predict.yml` — раз в 2 часа: генерация + резолв + коммит `data/*.json`
- `server/server.js` — бэкенд подписки (Telegram Stars): `/status`, `/trial`, `/pay`, long-polling; Node >= 18, без зависимостей
- `data/predictions.json` — прогнозы на сегодня (free/pro), `data/results.json` — накопленная история, `data/calibration.json` — Brier-калибровка, `data/archive/` — по дням

Фронтенд сначала показывает мок (локальное превью без хостинга), но как только `data/predictions.json` за сегодня доступен — переходит на реальные данные и честную статистику. Отменённые матчи считаются возвратом (push) и не портят проходимость.

## Модель `poisson-v2`

Всё считается из бесплатных данных ESPN, без API-ключей и без LLM-вызовов.

1. **Сила команд** — по таблицам лиги (голы за/против, очки): атака и оборона как множители к среднему лиги, с шринком при малой выборке. Если текущий сезон только начался (<3 матчей), берётся таблица прошлого сезона — она куда информативнее пустой.
2. **Распределение** — Пуассон для футбола и хоккея, нормальное приближение для NBA (очки — почти непрерывная величина). Из распределения получаются все рынки сразу: П1/Х/П2, тоталы (ТБ/ТМ), форы.
3. **Коэффициенты** — читаются реальные линии ESPN (moneyline/total), маржа снимается девигом. Модельная вероятность сравнивается с **честной** вероятностью линии.
4. **value** — если модель выше честной вероятности линии больше чем на 3%, рынок помечается `value` и попадает в PRO как value-ставка. FREE — самые надёжные прогнозы, PRO — ставки с перевесом. Так подписка покупает другую сущность, а не просто сортировку.
5. **Калибровка** — резолвер считает Brier score и reliability-таблицу по накопленной истории (`data/calibration.json`), а не зажимает проценты в коридор.

## Что уже работает

- 🎯 Экран «Прогнозы»: бесплатные прогнозы дня, фильтр по видам спорта
- 💎 Вкладка **PRO**: value-ставки Pro-ИИ с замком и пейволом
- 📊 Карточка показывает модель, коэффициент, вероятность линии и перевес модели; дополнительные рынки и разбор
- ⏳ Таймер обновлений витрины («Обновлено HH:MM · следующие через H:MM») и скелетоны карточек при загрузке
- 🎓 Онбординг из 3 шагов при первом визите (сохраняется в localStorage)
- 🎉 Конфетти на Статистике, если в последнем обновлении результатов был хит (раз в день, уважает prefers-reduced-motion)
- 👤 Профиль: аватар/имя из Telegram, стрик, визиты, XP-уровни, достижения
- 📈 Статистика: заходы/незаходы/проходимость за 14 дней — только по реальным завершённым матчам
- 💰 Оплата Telegram Stars: счёт ботом, 3-дневный триал, история платежей в «Управлении подпиской»
- 🛡️ Безопасность: `initData` проверяется по официальному алгоритму Telegram, история платежей отдаётся только владельцу, платежи идемпотентны (по `telegram_payment_charge_id`), `users.json` пишется атомарно

## Бэкенд подписки

1. `server/config.json` (не коммитится):
   ```json
   { "TOKEN": "токен бота", "STARS_PRICE": 3, "PORT": 8787, "MINIAPP_URL": "https://<адрес мини-аппа>/" }
   ```
2. `node server/server.js` (или `start-payments.bat`)
3. Если задан `MINIAPP_URL`, при старте бот сам поставит кнопку мини-аппа в чат (`setChatMenuButton`) и команды `/start`, `/subscribe`. Если ключ не задан — кнопка не трогается (чтобы не перебить настроенную через BotFather).

> ⚠️ Адрес в `CONFIG.API_BASE` внутри `index.html` — это URL бэкенда. Сейчас там cloudflared-туннель: он меняется при каждом перезапуске. Для продакшена нужен постоянный адрес (VPS, Railway, Cloudflare Worker и т.п.).

## Запуск локально

Просто открыть `index.html` в браузере — работает демо-режим (мок-данные, без сервера).

## Деплой

1. Разместить репозиторий на HTTPS-хостинге (сейчас — GitHub Pages: `https://xstayis-hue.github.io/pxax-predict/`)
2. В @BotFather: `/newapp` → указать URL (или задать `MINIAPP_URL` в config.json сервера)
3. Запустить `server/server.js` там, где он постоянно доступен, и прописать его адрес в `CONFIG.API_BASE`
