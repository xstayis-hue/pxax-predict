# PXAX AI Прогнозы — Telegram Mini App (v0.8)

Мини-приложение для Telegram: ежедневные прогнозы на спорт от ИИ для подписчиков.

⚠️ **Во всех экранах присутствует дисклеймер:** прогнозы генерирует ИИ, вероятность не 100%, ставки — риск, 18+. Валюта личного трекера ставок — условные единицы: не деньги, не платёжное средство и не имеют никакой реальной ценности.

## Архитектура

- `index.html` — всё приложение одним файлом (без сборки): UI, свайп-колоды, пейвол, личный трекер ставок
- `scripts/generate-predictions.mjs` — генератор прогнозов по данным ESPN (без ключей): таблицы лиг, линии, xG-форма (Understat), травмы (ESPN)
- `scripts/resolve-results.mjs` — резолвер: матчи последних 72 ч сверяются по id с реальными результатами ESPN (несыгранные возвращаются на следующий проход, отменённые — push) + калибровка
- `scripts/model.mjs` — распределение счёта (футбол/хоккей/NBA) + xG-бленд (общий для генератора и бэктеста)
- `scripts/backtest.mjs` — бэктест модели по завершённым матчам за 90 дней (без заглядывания: только форма до матча + средний тотал лиги) → `data/backtest.json`
- `.github/workflows/predict.yml` — раз в 2 часа: генерация + резолв + коммит `data/*.json`; `.github/workflows/backtest.yml` — бэктест ежедневно; `.github/workflows/deploy-payments.yml` — деплой воркера оплаты
- `worker/` — бэкенд подписки (Telegram Stars) на Cloudflare Worker: `/api/status`, `/api/trial`, `/api/invoice`, вебхук Telegram; постоянный адрес, без своего сервера (см. `worker/README.md`)
- `server/` — прежний Node-бэкенд через cloudflared-туннель; оставлен как запасной, для продакшена не используется
- `data/predictions.json` — прогнозы на сегодня (free/pro + `botd` «ставка дня»), `data/results.json` — накопленная история, `data/backtest.json` — ежедневный бэктест модели, `data/calibration.json` — Brier-калибровка, `data/archive/` — по дням

Фронтенд сначала показывает мок (локальное превью без хостинга), но как только `data/predictions.json` за сегодня доступен — переходит на реальные данные и честную статистику. Отменённые матчи считаются возвратом (push) и не портят проходимость.

## Модель

Всё считается из бесплатных данных ESPN + Understat, без API-ключей и без LLM-вызовов.

1. **Сила команд** — по таблицам лиги (голы за/против, очки): атака и оборона как множители к среднему лиги, с шринком при малой выборке. Если текущий сезон только начался (<3 матчей), берётся таблица прошлого сезона — она куда информативнее пустой.
2. **xG-форма (только футбол, топ-5 лиг)** — из Understat (`getLeagueData`): средние xG за/против за последние 5 *завершённых* матчей перед датой матча (без lookahead'а) корректируют ожидаемые голы на до ~10%. Если Understat недоступен или лига не покрывается — тихий fallback на гол-форму. К имени команды матчинг: точное → алиасы → префикс → срез клубных префиксов («AFC Bournemouth», «AS Roma»).
3. **Распределение** — распределение счёта для футбола и хоккея, нормальное приближение для NBA (очки — почти непрерывная величина). Из распределения получаются все рынки сразу: П1/Х/П2, тоталы (ТБ/ТМ), форы.
4. **Коэффициенты** — читаются реальные линии ESPN (moneyline/total), маржа снимается девигом. Модельная вероятность сравнивается с **честной** вероятностью линии.
5. **value** — если модель выше честной вероятности линии больше чем на **5%**, рынок помечается `value` и попадает в PRO как value-ставка (порог 5%: меньше — шум). FREE — самые надёжные прогнозы, PRO — ставки с перевесом.
6. **Травмы** — league-level endpoint ESPN (`.../injuries`): до 3 injured-игроков на команду со статусом (Out/Doubtful/Probable/…) добавляются в `note` матча.
7. **Калибровка** — резолвер считает Brier score и reliability-таблицу по накопленной истории (`data/calibration.json`), а не зажимает проценты в коридор.

## Новые фичи v0.8

- 💳 **Оплата Stars напрямую в вебвью.** Счёт открывается через `openInvoice` (бот присылает ссылку `createInvoiceLink`), не нужно искать сообщение в чате. Цена, срок и длительность пробы берутся из ответа сервера — во фронтенде нет ни одного захардкоженного числа плана.
- 🔒 **Пейвол без утечки VIP-прогноза.** Заблокированная карточка не рендерит рынок, кэф, перевес и разбор вовсе; ноги «Ставки дня» без подписки тоже не выводятся (см. раздел ниже).
- 🎞️ **Переходы между вкладками без «проявления» прошлого экрана.** Анимация входа перестала быть полупрозрачной, поэтому `backdrop-filter` на шапке и таббаре больше не подмешивает в фон предыдущий кадр.
- ☁️ **Бэкенд оплаты на Cloudflare Worker** (`worker/`): постоянный адрес вместо cloudflared-туннеля, KV-хранилище, идемпотентные платежи по `telegram_payment_charge_id`, 9 автотестов, деплой из CI.

## Новые фичи v0.7

- 🧾 **Личный трекер ставок + ROI.** На карточке — кнопка «Я поставил» (localStorage, без сервера). Как только матч появляется в `results.json`, P/L считается автоматически: win = (kэф−1)·stake, miss = −stake, push = 0. В профиле: P/L, ROI, проходимость, текущий стрик, размер ставки (усл. ед.), последние 12 ставок. Валюта трекера — исключительно условная: не деньги и не имеет никакой реальной ценности.
- 💎 **«Ставка дня» (PRO-экспресс).** Генератор собирает экспресс из 2–3 сигналов: только уверенность ≥70% у каждой ноги, приоритет value-рынков. Показывается в PRO-вкладке с суммарным кэфом и совместной вероятностью модели; без PRO — за замком.
- 📊 **xG-форма** в футбольных прогнозах (top-5 лиг) — см. п.2.
- ⚡ **Value-порог 5%** вместо 3% — fewer false value-badges.
- 🏥 **Травмы в разборе матча** (ESPN injuries) — см. п.6.
- 📡 **Честный статус «собираем данные».** Пока живых завершённых матчей меньше 20 — плашка с количеством сыгранных и явной пометкой, что цифры недостоверны; при нуле — ориентир на бэктест модели.

## Что уже работает

- 🎯 Экран «Прогнозы»: бесплатные прогнозы дня, фильтр по видам спорта
- 💎 Вкладка **PRO**: value-ставки Pro-ИИ с замком и пейволом
- 📊 Карточка показывает модель, коэффициент, вероятность линии и перевес модели; дополнительные рынки и разбор
- ⏳ Таймер обновлений витрины («Обновлено HH:MM · следующие через H:MM») и скелетоны карточек при загрузке
- 🎓 Онбординг из 3 шагов при первом визите (сохраняется в localStorage)
- 👤 Профиль: аватар/имя из Telegram, стрик, визиты, XP-уровни, достижения
- 📈 Статистика: заходы/незаходы/проходимость за 14 дней — только по реальным завершённым матчам
- 💰 Оплата Telegram Stars: счёт открывается прямо в вебвью (`openInvoice`), цена и срок берутся с сервера, есть пробный период и история платежей в «Управлении подпиской»
- 🛡️ Безопасность: `initData` проверяется по официальному алгоритму Telegram, история платежей отдаётся только владельцу, платежи идемпотентны (по `telegram_payment_charge_id`)

## Пейвол без утечки прогноза

Заблокированная карточка дольше не «прятала» прогноз фильтром `blur` — рынок, коэффициент,
перевес и разбор лежали в DOM и в кадре до применения фильтра читались. Теперь для
неподписчика эти поля в разметку вообще не рендерятся (обезличенные плейсхолдеры), а ноги
«Ставки дня» и её суммарный кэф тоже не выводятся. Плюс анимация перехода между вкладками
перестала быть полупрозрачной: липкая шапка и таббар с `backdrop-filter` больше не
подмешивают в фон кадр предыдущей вкладки, из-за чего под блюром на миг «проявлялись» VIP-ставки.

## Бэкенд подписки

Продакшен — Cloudflare Worker в `worker/` (постоянный адрес, без туннеля):

1. `wrangler kv namespace create USERS` → id в `worker/wrangler.toml`
2. `wrangler secret put BOT_TOKEN`, `WEBHOOK_SECRET`, `ADMIN_KEY`
3. `wrangler deploy`, затем один раз `setWebhook` на `https://<воркер>/tg/<WEBHOOK_SECRET>`
4. `node worker/link.mjs https://<воркер>` — прописывает адрес в `CONFIG.API_BASE` внутри `index.html`
5. Цена и сроки задаются в `worker/wrangler.toml` → `[vars]` (`STARS_PRICE`, `PRO_DAYS`, `TRIAL_DAYS`); фронтенд берёт их из `/api/status` и ничего не хардкодит

Тесты: `node worker/test/payments.test.mjs`. Подробности и деплой из CI — в `worker/README.md`.

Прежний Node-бэкенд: `server/config.json` с `TOKEN` → `node server/server.js` (long-polling, свой сервер + туннель).

## Что дальше

1. **Калибровка на длинной истории.** Brier-механизм уже есть, нужно накопить данные и подтянуть веса модели под reliability-таблицу. Уже сейчас видно, что модель переоценивает себя: в `calibration.json` бакет 0.7–0.8 дал 50% факта, 0.8+ — 0%. Выборка пока маленькая (24 наблюдения), но это та метрика, за которую стоит держаться.
2. **Не выдавать прогнозы на предсезонных матчах.** NBA сейчас в preseason (ESPN `season.type = 1`): команды играют ротацией, а модель считает по таблицам регулярки. Отсюда «перевес модели +66%» на тотале и 4 из 5 PRO-ставок дня из NBA. В `generate-predictions.mjs` есть фильтр `status.type.state !== 'pre'` (состояние «до матча»), но типа сезона там нет — стоит отбрасывать `season.type === 1`.
3. **Проверить расхождение модельного и рыночного тотала в NBA.** Снапшот линии 220.5 при модельных 236 очках — это 16 очков разрыва, слишком много для честного «перевеса». Нужно понять, устаревшая это линия ESPN или неверный парсинг `overUnder`, и пока не разобрались — не показывать такие рынки как value.
4. **LLM-разбор**: заменить текстовые `note` на запрос к LLM с пост-валидацией по числам (сейчас разбор строится шаблонно из чисел модели).
5. **Уведомления ботом**: «прогнозы на сегодня готовы», «твой прогноз зашёл», напоминание об окончании подписки.
6. **Сводки по подпискам вынести из перебора KV**: `/api/admin/stats` листает все ключи, на росте это станет и медленно, и дорого — под это место нужен отдельный индекс или D1.
7. **xG на другие лиги** (MLS/Лига MX/Бразилия) — когда Understat их даст; сейчас fallback на гол-форму.
8. **Экспорт личного ROI** (CSV/скриншот) для отмеченных ставок.
9. **Серверный пейвол.** Сейчас PRO-прогнозы лежат в публичном `data/predictions.json` вместе с `tier` и ногами «Ставки дня» — то есть весь VIP-контент скачивается без подписки, а пейвол только скрывает его в интерфейсе. Чтобы это была настоящая платная часть, генератору нужно писать два файла: `predictions.json` (только free + счётчики) и закрытый `pro.json`, который отдаёт лишь бэкенд и только по валидному `initData` с активной подпиской.

## Запуск локально

Просто открыть `index.html` в браузере — работает демо-режим (мок-данные, без сервера).

## Деплой

1. Разместить репозиторий на HTTPS-хостинге (сейчас — GitHub Pages: `https://xstayis-hue.github.io/pxax-predict/`)
