# PXAX AI Прогнозы — Telegram Mini App (v0.2)

Мини-приложение для Telegram: ежедневные прогнозы на спорт от ИИ для подписчиков.

⚠️ **Во всех экранах присутствует дисклеймер:** прогнозы генерирует ИИ, вероятность не 100%, ставки — риск, 18+.

## Что уже работает (v0.2)

- 🎯 Экран «Прогнозы»: 3 бесплатных прогноза в день от базового ИИ
- 💎 Отдельная вкладка **PRO**: 2–4 прогноза в день от Pro-ИИ (value-ставки, скан линий)
- 👤 Профиль: аватар/имя из Telegram, стрик дней, число визитов
- 📊 Статистика: заходы/незаходы/проходимость за 14 дней (экраны Профиль и История)
- ✨ Анимации: «ИИ думает» при входе, каскадное появление карточек, анимация полос уверенности, шиммер на замках, живые табы
- 💰 Пейвол PRO: тарифы, CTA, демо-переключатель подписки
- 📊 История прогнозов с результатами (зашёл/не зашёл) + статистика сверху
- 🛡️ Эмблемы команд загружаются из ESPN; реальные коэффициенты букмекеров пока не подключены и не показываются
- 🪙 3D-баннер с монеткой PXAX — отложено (модель готова в assets/)
- 🎨 Тёмная неоновая тема, адаптация под Telegram (expand, тема, безопасные зоны)

## 3D-модель

- `assets/coin.glb` — модель монетки (Blender, процедурная генерация)
- `tools/make_coin.py` — скрипт генерации: `blender --background --python tools/make_coin.py`
- Модель также встроена в `index.html` (base64), при деплое можно переключить на загрузку файла

## Что дальше (v0.2+)

1. **Бот**: создать бота у @BotFather, привязать Mini App (`/newapp` или Bot Settings → Menu Button)
2. **Бэкенд**: Node.js + SQLite/Postgres — генерация прогнозов через LLM API (OpenAI/DeepSeek) или локальная модель (Ollama), таблицы `users`, `subscriptions`, `predictions`, `results`
3. **Оплата**: Telegram Stars (`sendInvoice` с `provider = stars`) или внешняя ссылка; проверка платежа вебхуком
4. **Реальный ИИ**: подмена мок-генератора на запрос к LLM с пост-валидацией + запись в БД
5. **Статистика**: считать реальную проходимость по завершённым матчам (API спортивных данных)

## Запуск локально

Просто открыть `index.html` в браузере — работает демо-режим.
Кнопка «🔧 Демо: включить PRO» в профиле переключает подписку (localStorage).

## Деплой

1. Разместить `index.html` на любом HTTPS-хостинге (GitHub Pages, Vercel, Cloudflare Pages)
2. В @BotFather: `/newapp` → указать URL
3. Заменить `CONFIG.SUBSCRIBE_URL` в `index.html` на юзернейм бота
4. (v0.2) добавить вебхук-бэкенд и реальную оплату
